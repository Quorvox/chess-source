# Звуки

Набор `sfx` из репозитория https://github.com/lichess-org/lila (папка public/sound/sfx), автор Enigmahack,
лицензия AGPLv3+ (см. COPYING.md в lila). Использованы файлы: Move, Capture, Check, Victory, Defeat, Draw,
GenericNotify, LowTime, NewChallenge. Из-за AGPL исходный код QuorChess должен быть доступен пользователям сайта.
